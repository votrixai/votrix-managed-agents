Votrix Managed Agents (VMA) is an API-first **agent harness framework**. It
gives every Agent a sandbox where it can use tools, work with files, and carry
multi-step jobs through to completion.

You define what an Agent should do and send it work through the API. VMA keeps
the Agent, its sandbox, its files, and the history of the job connected in one
Session, so your product does not have to rebuild that surrounding system for
every workflow.

## What VMA gives you

- **Reusable Agents** — define a role, instructions, tools, and Skills once,
  then use that Agent for many jobs.
- **A sandbox for real work** — let an Agent use tools, read inputs, create
  files, and complete work that takes more than one step.
- **Ongoing Sessions** — send follow-up messages or feedback while keeping the
  same work and conversation together.
- **Files and shared memory** — provide source material, collect deliverables,
  and make useful context available across Sessions.
- **Live progress and control** — follow events as they happen, approve actions,
  answer custom tools, or interrupt a turn.

VMA is a good fit for research, content production, analysis, operations, and
other work where an Agent needs tools, files, or continuity beyond one model
response.

## How it works

1. **Create an Agent** with a job, instructions, and the capabilities it needs.
2. **Start a Session** with an Environment and any Files or Memory Stores.
3. **Send a message** describing the work.
4. **Follow Session events** until the Agent finishes or asks for input.
5. **Collect the result** and continue the same Session when needed.

## The main resources

| Resource | What it represents |
| --- | --- |
| **Agent** | A reusable worker with instructions, tools, and Skills. |
| **Environment** | The sandbox setup available to an Agent. |
| **Session** | One ongoing job, including its history and sandbox. |
| **Account** | The usage and spending boundary for a Session. |
| **Skill** | Reusable guidance for a particular kind of work. |
| **File** | An input supplied to an Agent or an output it creates. |
| **Memory Store** | A shared workspace that can continue across Sessions. |
| **Event** | An ordered update in a Session, from you or the Agent. |

<Callout title="Public contract" type="info">
