The Votrix Managed Agents API is an Organization-scoped REST API for defining agents,
creating durable sessions, managing execution environments, and operating the
resources that long-running agents need.

The public-beta document contains API keys, Agents, Environments, Sessions,
Files, Skills, Vaults/native model Credentials, Model Providers, and the
capability manifest. Experimental repository routes such as Memory Stores,
Deployments, User Profiles, Session Threads, presigned-upload completion, and
webhook delivery are intentionally excluded from the GA schema.

<Callout title="Authentication">
  Every `/v1` request requires the current `votrix-managed-agents-beta` header plus
  either an `x-api-key` header or the same key as a Bearer token. Authentication
  values entered in the playground stay in your browser.
</Callout>

Every response echoes or generates `request-id` and `x-request-id`. Standard
API error envelopes expose a stable `error.code` and include the request ID;
quota denials also include `X-RateLimit-*` or `X-Quota-*` reset metadata.

## Base URL

```text
https://vma.votrixai.com
```

Choose an endpoint from the sidebar to inspect its request schema, copy a code
sample, or send a real HTTP request from the interactive playground.

## OpenAPI document

The reference is generated at build time from the same FastAPI application that
serves production traffic. You can also [download the complete OpenAPI schema](/openapi/vma.json).
