<Callout title="Development authentication boundary" type="warn">

Organization-scoped routes require `x-organization-id`. The active rewrite
currently trusts that value and accepts, but does not validate, an optional
`x-api-key`. Do not expose this service directly to untrusted clients until
authentication and authorization are implemented.

</Callout>

The endpoint pages below are generated from the same `app.server.create_app`
application used by the service. The committed schema is available at
`/openapi/vma.json`; a running VMA instance exposes the same route and model
surface at `/openapi.json`.

To refresh the checked-in reference after changing a route or model:

```bash
cd website
npm run openapi:sync
```

Memory Store, Memory, and immutable Memory Version endpoints are grouped under
**Memory Stores**. See [Memory Stores](../memory-stores.md) for lifecycle and
consistency semantics and [Memory Stores on E2B Volumes](../memory-volumes.md)
for Sandbox mounting and runtime writeback.

For local interactive requests, start the service with:

```bash
uv run uvicorn app.main:app --reload
```
